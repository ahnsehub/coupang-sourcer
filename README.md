# 쿠팡 AI 꿀통키워드 소싱기

앤더슨 키워드파인더와 같은 흐름(티어 선택 → 고급 필터 → 등급별 키워드 + 효자상품)을 내 PC에서 돌리는 도구입니다.

## 동작 방식
1. **씨앗 키워드**(카테고리별 기본값 또는 직접 입력) → **네이버 검색광고 API**로 연관 키워드 + 월 검색량 확장
2. 선택한 티어 매출에 맞을 법한 검색량 구간에서 후보를 고름 (기본 20개, 중심값에 가까운 순). 조건에 안 맞은 키워드도 이유와 함께 표로 표시
3. 후보마다 **쿠팡 검색 1페이지**의 광고 제외 상위 10개 상품 가격·리뷰수·로켓배송 여부 수집 — 기본은 **수동 보조 모드**: 앱의 링크로 쿠팡 검색 → 북마크 `쿠팡소싱복사` 클릭 → 앱에 붙여넣기 (자동 크롬 방식은 쿠팡이 봇으로 차단함)
4. **데이터랩 12개월 추이**(급상승·계절성) 추가
5. 판매량·매출 추정 → 점수(0~100) → 등급 S+/S/A/B, 태그 부여 → 티어·필터 조건에 맞는 것만 표시
6. (선택) Claude API로 키워드별 진입판단·차별화·리스크 코멘트

## 지표 정의 (중요: 판매량·매출은 추정치)
| 지표 | 계산 |
|---|---|
| 추정 월판매 | 월 검색량 × 쿠팡/네이버 비율 × 구매전환율 × 순위별 점유율(1위 20%, 2위 13% …) |
| 추정 월매출 | 상품별 추정 월판매 × 판매가, 상위 10개 합 |
| 효자상품 | 추정 월매출 1위 상품. 이 상품의 리뷰수로 진입난이도 판단 |
| 점수 | 수요 25% + 진입난이도 25% + 경쟁(네이버 광고경쟁도 + 쿠팡 상위10 리뷰 밀도) 20% + 로켓공백 15% + 단가 15% |
| 등급 | S+ ≥80, S ≥70, A ≥58, B 그 외 |
| 태그 | 급상승(지난달/직전3개월 ≥1.3배), 계절성(12개월 최대/최소 ≥3배), 신규(효자상품 리뷰 ≤50), 블루오션(광고경쟁도 낮음 + 상위10 리뷰합 <1,000), 로켓공백(로켓 ≤30%), 고단가(평균가 ≥3만원) |

전환율·비율은 사이드바에서 조정됩니다. 내가 실제 판매 중인 상품(예: 거울, 액자걸이)의 키워드로 돌려 보고 Wing의 실제 판매량과 맞도록 보정하는 것을 권장합니다.

## 웹으로 쓰기 (권장)
`배포가이드_웹.md` 참고 — Streamlit Cloud에 올려 주소만 열면 어느 컴퓨터에서나 사용 (비밀번호 잠금).

## 내 PC에서 실행 (Windows, 최초 1회)
1. Python 3.11 이상 **x64 버전** 설치 (python.org → "Windows installer (64-bit)", 설치 시 "Add python.exe to PATH" 체크). Surface 등 ARM PC에서도 ARM64가 아닌 x64 버전을 설치해야 합니다(Streamlit이 쓰는 pyarrow가 ARM64 Windows 미지원).
2. 이 폴더의 `설치.bat` 더블클릭
3. 생성된 `.env` 파일을 메모장으로 열어 API 키 입력
4. `실행.bat` 더블클릭 → 브라우저에 앱이 열림

키가 없으면 **데모 모드(가짜 데이터)**로 화면만 확인할 수 있습니다.

## API 키 발급
- **네이버 검색광고 API (필수)**: searchad.naver.com 가입 → 도구 → API 사용 관리 → 액세스라이선스/비밀키/CUSTOMER_ID
- **네이버 데이터랩 (권장)**: NAVER API HUB(네이버클라우드) → Application 생성 → "검색어 트렌드" → Client ID/Secret. 기존 developers.naver.com 키도 2027-06-30까지 동작. (네이버 쇼핑 검색 API는 2026-07-31 종료)
- **Claude API (선택)**: console.anthropic.com

## 주의
- 북마크 설치: 크롬 북마크바 우클릭 → 페이지 추가 → 이름 `쿠팡소싱복사`, URL에 `쿠팡소싱복사_북마크코드.txt` 내용 전체 붙여넣기.
- 조회 결과는 `sourcer_cache.db`에 7일간 캐시되어 같은 키워드는 다시 조회하지 않습니다.
- 쿠팡 화면 구조가 바뀌면 `sourcer/coupang.py`의 `SELECTORS`를 수정해야 합니다(2026-10 기준 확인).
